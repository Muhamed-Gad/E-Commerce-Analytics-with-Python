# 🧹 Clean Data Folder

This folder is designed to store the processed and engineered datasets generated by the project's scripts. 

Since some of the cleaned files (like the massive `order_fact_clean.csv`) exceed GitHub's file size limits, they are not included in the repository by default.

## 📥 How to get the data:
**Option A: Generate it yourself (Recommended)**
Run Notebook `01_data_ingestion_and_profiling.ipynb` and `02_cleaning_and_feature_engineering.ipynb`. The scripts will automatically process the raw data and save the clean CSV files directly into this folder.

**Option B: Download the pre-cleaned data**
If you want to skip the cleaning phase, you can download the clean `.csv` files directly from this Google Drive link:
👉 [**Download Clean Data Here**](https://drive.google.com/drive/folders/19Afl59JicuMqN7ksBxqiAdqSOz0itwfw?usp=drive_link)

*Make sure to place the downloaded files directly into this `clean_data/` directory before running notebooks 03 and 04.*
