# 📊 Tables For Insights Folder

This folder contains all the aggregated summary tables and CSV/Excel reports generated during the Exploratory Data Analysis (EDA) and RFM Segmentation phases. 

These datasets are highly optimized, structured, and ready to be directly imported into BI tools like **Power BI** or **Tableau** for building interactive dashboards.

## 📥 How to get the tables:
**Option A: Generate them yourself (Recommended)**
Run all the Jupyter notebooks in the `scripts/` folder in sequential order (from `01` to `04`). The code will automatically group, aggregate, and export the resulting tables directly into this folder.

**Option B: Download the pre-generated tables**
If you want to skip the Python execution and jump straight into building BI dashboards, you can download the final output tables directly from this Google Drive link:
👉 [**Download Tables Here**](https://drive.google.com/drive/folders/19Afl59JicuMqN7ksBxqiAdqSOz0itwfw?usp=drive_link)

*Note: If you download them manually, please extract and place the `.csv` and `.xlsx` files directly into this `tables/` directory.*
